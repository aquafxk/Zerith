# Downloader v3.0.28

As opções multimídia novas foram direcionadas somente ao TikTok:
- Automático: tenta vídeo e fotos/slideshow.
- Somente fotos/slideshow.
- Somente vídeos.

Instagram conserva o suporte multimídia que já existia. X/Twitter permanece somente para vídeos.

Não há chave de API do TikTok a cadastrar para yt-dlp/gallery-dl. Essas ferramentas extraem mídia publicamente disponível, mas podem parar de funcionar quando a plataforma muda ou impõe limites. GitHub não fornece APIs ilimitadas.
